# TUITEA brand kit

One source image drives the app icon, the invite page, the share preview, the install
page and the web manifest icons.

- `source.png` — 1024×1024, square, no transparency. Currently a placeholder mark;
  replace it with the approved artwork.
- `brand.json` — the product name, and the background colour used behind the share card.
- `share.png` — the 1200×630 share card, used as the `og:image` on `/join/`.

Background colour: `#1B2B34`.
