`node --test assets/js/door-scanner.test.mjs`: 31 tests, real `door.html` + real `kil-door-scanner.js` in jsdom with a fake Supabase client, fake `fetch`, fake `BarcodeDetector`/`getUserMedia`. Covers: payload table (raw, `KIL-`, `kil-`, whitespace, double prefix, URL-form, garbage, empty, oversize); the RPC call (URL, method, user token as bearer, anon key only as `apikey`, body keys = `p_qr_token`); no session -> redirect before any RPC; code stripped from URL; each result code -> state/tone/focus/aria-live; unknown/garbage server replies -> error; 401/403/42501 -> sign-in state with camera stopped and server message not shown; session lost mid-use -> no network call; network failure/500/502 never show Admitted and retry works; duplicate scans debounced, in-flight submits ignored; evil response with buyer/email/handle/phone/name/token/order keys never reaches DOM text or attributes; hostile event title rendered as text; camera scan -> one RPC, loop paused while result shown, resumes on "Scan next", still debounced; stream stopped on `pagehide`, hidden visibility, Stop, sign-out; unsupported/denied/no-camera paths; no web storage/cookies/console; no third-party script, noindex, no zoom lock, 44px-plus targets, input has no `name`; door.html is referenced by nothing else; adapter copy byte-identical to PR #137.

## A2. 15B: jsQR fallback (offline, this PR)
`node --test assets/js/door-scanner-qr.test.mjs`: 20 tests. The 31 tests above still pass unchanged except one: "BarcodeDetector without qr_code" now asserts the jsQR fallback (decoder load failure -> `decoder` reason, stream stopped) instead of `unsupported`.
* **Generated-QR decode**: QR images are generated at test time with the repo's already-shipped `assets/js/vendor/qrcode.js` encoder (the one the ticket pages use; no new dependency, nothing committed as a fixture), rendered to RGBA with a 4-module quiet zone at scales 3/4/6/8 and error-correction L/M/Q, for 6 tokens each raw and `KIL-`-prefixed (12 payloads x 4 scales x 3 EC levels = 144 images); the vendored jsQR must return the EXACT text. The decoded text then goes through the real `localParse` to the same `p_qr_token`.
* **Real frame path**: the real `door.html` + scanner in jsdom, fake `<video>` whose frames are generated QR images placed in a 1280x720 frame, a fake canvas that nearest-neighbour downscales, the REAL jsQR delivered through the REAL lazy loader (script element asserted, `load` fired by the test after evaluating the vendored file). Asserts: nothing loaded before Start; script requested only on the fallback path; frames <= 640 px wide; exactly one RPC with the user bearer and stripped token; 110 ms timer; no frame read while a result is up or the tab is hidden; Scan next resumes; same ticket still debounced.
* **Negative controls**: blank / black / noisy frames decode to null and send nothing; QR holding a URL, `http://` URL, text with spaces, a 129-char payload or a multi-line vCard is refused locally ("Not a KEEPITIL ticket") and never sent, and is not echoed into the page; light-on-dark QR does not decode (documents `dontInvert`); with `BarcodeDetector` + `qr_code` present NO script element, no `window.jsQR`, loader never called; without it (or without `qr_code`, or if `getSupportedFormats` throws) it IS loaded; loader `onerror` or a script that defines no `jsQR` -> clear message, stream stopped, manual entry works, retry re-requests; one flipped byte / appended comment / CRLF conversion of the vendored file fails the SHA-256 check (also verified by hand: appending `//tamper` to the real file turned the test red, restoring it turned it green).
* **Supply chain**: SHA-256 of `jsQR.js` equals the value recorded in `assets/js/vendor/jsqr/README.md` AND a second pin inside the test; `LICENSE` is the Apache-2.0 text with its own hash; README carries name, exact version, publish date, source, tarball integrity; the file contains no network/storage/`eval` APIs and defines `window.jsQR` as a classic script.
* **Real browser** (headless Chrome 15B harness, `evidence/d1-harness.mjs`): `BarcodeDetector` removed, `getUserMedia` returns a `canvas.captureStream()` of a generated QR, supabase client and RPC mocked, everything else real (real `<video>`, real canvas `getImageData`, real lazy `<script>` over HTTP). Result in `evidence/d1-harness-report.json` + `d1-375-*.png`: `window.jsQR` undefined before Start and `function` after; `jsQR.js` requested exactly once; blank frame -> `idle`, no RPC; raw and `KIL-` QR -> `admitted` with one RPC, bearer = the (fake) user token, body `{"p_qr_token":"0123...cdef"}`; URL QR -> "Not a KEEPITIL ticket", zero RPCs; no horizontal scroll at 375 px.
