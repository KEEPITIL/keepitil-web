# Launch music

Put the owner-supplied, TUITEA-authorised excerpt of **Roots in Motion** (by TUITEA) here as:

    roots_in_motion_intro.m4a

10–15 s of the chorus, AAC in .m4a. The app plays it at launch ONLY if this file exists; until
then TUITEA launches silently. Never download or rip it from Spotify. The path is
`AppBrandConfig.launchMusicAsset`.
