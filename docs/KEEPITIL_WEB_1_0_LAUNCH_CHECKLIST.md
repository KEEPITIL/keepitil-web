## 3. Deploy and rollback
- **Deploy:** `keepitil-web` `main` is published to keepitil.com by the Pages workflow; each PR needs Grok's sha-pinned GO and is merged by KODE. Event pages regenerate by running the "Event pages" workflow (it pushes a `prerender/run-<id>` branch; a person opens the PR).
- **Rollback of a page change:** revert the merge commit on `main`; Pages redeploys the previous files. No data migration is involved in page changes.
- **Rollback of the prerender:** revert the commit that added `event/` and `sitemap-events.xml` changes; the legacy `/event?e=` page is untouched and keeps working. The workflow variable `EVENT_PRERENDER` set to anything but `on` stops new runs.
- **Rollback of database changes:** each pack in `keepitil.github.io/.github/internal/docs/owner-security/` ships a ROLLBACK file (verified on a local Postgres): follows, anon-config, F7 (`definer-anon/ROLLBACK.sql`, `group-c-ROLLBACK.sql`). A restore needs the owner's GO and the backup taken before the apply.
- **Kill switches without a deploy:** `EVENT_PRERENDER` (stops the generator); feature flags for money features are off in code. There is no site-wide kill switch; Cloudflare can serve a maintenance rule (Grok).

## 4. Live checks after each deploy (read-only, copy and run)
```bash
B=https://keepitil.com
# 1. pages, status and canonical
for p in "" about artists business venues/ connect/ create/ culture/ earn/ support/ signup apply terms privacy event/stick-figure/; do
  echo "/$p http=$(curl -s -o /tmp/p.html -w '%{http_code}' "$B/$p") canonical=$(grep -c 'rel="canonical"' /tmp/p.html)"; done
# 2. private pages are noindex, unknown paths are real 404s
for p in settings submit-event dashboard reset-password; do echo "/$p noindex=$(curl -s "$B/$p" | grep -ci noindex)"; done
curl -s -o /dev/null -w 'notfound=%{http_code}\n' "$B/nothere-xyz"
# 3. sitemaps
curl -s -o /dev/null -w 'sitemap=%{http_code}\n' "$B/sitemap.xml"; curl -s "$B/sitemap-events.xml" | grep -c '/event/.*/</loc>'; curl -s "$B/sitemap-events.xml" | grep -c 'event?e='
curl -s "$B/robots.txt" | grep -i sitemap
# 4. no source maps, no service key
curl -s "$B/" | grep -ci 'sourceMappingURL'; curl -s "$B/" | grep -ci "service_[r]ole"
# 5. money features stay off (no Stripe script, no refund UI)
for p in submit-event settings dashboard; do echo "/$p $(curl -s "$B/$p" | grep -ci 'js.stripe.com\|checkout.stripe.com\|refund')"; done
# 6. security headers (not on /app/)
curl -sI "$B/" | grep -i -E '^(x-content-type-options|referrer-policy|permissions-policy)'
curl -sI "$B/app/" | grep -ci -E '^(x-content-type-options|referrer-policy|permissions-policy)'
```
